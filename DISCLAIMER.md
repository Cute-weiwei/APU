# Responsible Use

APK Unpack Agents is intended for lawful security research, education, interoperability, software preservation, debugging, and analysis of software you own or are explicitly authorized to examine.

The tool does not grant permission to inspect, modify, install, extract, intercept, or reverse engineer third-party software or devices. You are responsible for obtaining the required authorization and for complying with applicable laws, contracts, platform rules, and third-party tool licenses.

The project may start processes, communicate with Android devices, read process memory, install an APK when explicitly requested, and apply reversible device changes during an investigation. Review the generated run plan, `mutations.json`, logs, and cleanup result before and after each run.

Results are evidence with scope and limitations. A shell signature is not proof of complete recovery. A valid DEX checksum is not proof that every class was recovered. A partial JADX output is not proof of a complete source reconstruction.
